# Smart Retail AI Intelligence Platform

## Overview
Smart Retail AI Intelligence Platform is an AI-based retail management system developed using Python and FastAPI. It provides product classification, face recognition, sentiment analysis, an AI chatbot, and dashboard analytics.

## Features
- Product Classification
- Face Recognition
- Sentiment Analysis
- AI Chatbot
- Dashboard Statistics
- FastAPI REST APIs

## Technologies
- Python
- FastAPI
- OpenCV
- TensorFlow
- Scikit-learn
- Pandas
- NumPy

## Run the Project

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the server:

```bash
uvicorn app.main:app --reload
```

Open in browser:

```
http://127.0.0.1:8000/docs
```
